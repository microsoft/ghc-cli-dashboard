# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/microsoft/ghc-cli-dashboard/issues)
to track bugs and feature requests. Search existing issues before opening a
new one to avoid duplicates.

Do not include Copilot usage exports, generated dashboards, project names,
task summaries, session IDs, credentials, or other personal/confidential data
in issues. For security vulnerabilities, follow the reporting instructions in
[SECURITY.md](SECURITY.md) instead of opening a public issue.

## Microsoft Support Policy

Support for this project is limited to the resources listed above.
